# Automação de Gráficos em Python

Projeto desenvolvido em Python com foco em automação de gráficos, manipulação de dados e exportação de informações para Excel.

## Tecnologias Utilizadas

* Python
* OpenPyXL
* Programação Orientada a Objetos
* Excel

## Funcionalidades

* Importação de dados
* Geração automática de gráficos
* Manipulação e organização de informações
* Exportação para planilhas Excel
* Estrutura modular separada por arquivos

## Estrutura do Projeto

* `Grafico.py` → geração de gráficos
* `Estatisticas.py` → cálculos estatísticos
* `Excel.py` → exportação e manipulação de planilhas
* `Importador.py` → importação de dados

## Objetivo

Praticar automação de tarefas, manipulação de dados e desenvolvimento de aplicações utilizando Python.

## Status do Projeto

Projeto em desenvolvimento e evolução contínua.
